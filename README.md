## Prerequisites
**Make sure you have the following installed on your machine:**

Node.js (which includes npm)

Git

## Step 1: Clone or Download the Repository
**Clone the entire project repository to your local machine using Git:**

```Bash
git clone [https://github.com/AbdullahCampoamor/Ecommerce.git](https://github.com/AbdullahCampoamor/Ecommerce.git)
cd Ecommerce
```
**(Alternatively, you can download the project as a ZIP file from GitHub and extract it).**


**Open the main root folder of the project in your code editor (like VS Code) or terminal.**

## Step 2: Run the Backend in a Separate Terminal
**Open your terminal and navigate to the backend directory:**

```Bash
cd ecommerce-backend
```
**Install the required dependencies:**

```Bash
npm install
```
**Start the backend server:**

```Bash
npm start dev
```
(Keep this terminal window open so the backend server stays active).

## Step 3: Run the Frontend in Another Separate Terminal
Open a new, separate terminal window while remaining in the root folder.

**Navigate to the frontend directory:**

```Bash
cd ecommerc-project
```
**Install the required dependencies:**

```Bash
npm install
```
**Start the frontend development server:**

```Bash
npm run dev
```
(Or npm start, depending on your configuration).
## Step 4: Access the Application
Open your web browser and go to the local address provided by your frontend terminal (usually http://localhost:5173 or http://localhost:3000).

You can now browse products, manage your shopping cart, and use the full-stack e-commerce features!
